# Topics

A topic note gathers everything the vault holds on **one concept** —
where it is defined, every regulation that uses it, and the AIM guidance
around it — so a concept can be studied without knowing which part of
which source to search. Topic notes are **curated**: the generator never
touches this folder.

## Available topics

- [[Cross-Country Flight]] — what counts as cross-country time, and the
  student/private pilot requirements built on it

## Writing a topic note

- Lead with where the concept is **defined** ([[1.1|§ 1.1]], [[61.1|§ 61.1]],
  or a [[PCG]] term note).
- Link every regulation and AIM paragraph that turns on the concept; open
  the definition note's **backlinks** pane to find candidates.
- Transclude a short authoritative passage with `![[91.155]]` instead of
  retyping it — official wording should live in one place.
