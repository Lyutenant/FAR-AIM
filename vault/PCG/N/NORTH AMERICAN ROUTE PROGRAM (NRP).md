# NORTH AMERICAN ROUTE PROGRAM (NRP)

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-n.html#NORTH_AMERICAN_ROUTE_PROGRAM_NRP)

## Official Text

NORTH AMERICAN ROUTE PROGRAM (NRP)- The NRP is a set of rules and procedures which are designed to increase the flexibility of user flight planning within published guidelines.
