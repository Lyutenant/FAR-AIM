# NATIONAL BEACON CODE ALLOCATION PLAN AIRSPACE (NBCAP)

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-n.html#NATIONAL_BEACON_CODE_ALLOCATION_PLAN_AIRSPACE_NBCAP)

## Official Text

NATIONAL BEACON CODE ALLOCATION PLAN AIRSPACE (NBCAP)- Airspace over United States territory located within the North American continent between Canada and Mexico, including adjacent territorial waters outward to about boundaries of oceanic control areas (CTA)/Flight Information Regions (FIR).
