# PRE-DEPARTURE CLEARANCE

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-p.html#PRE-DEPARTURE_CLEARANCE)

## Official Text

PRE-DEPARTURE CLEARANCE- An application with the Terminal Data Link System (TDLS) that provides clearance information to subscribers, through a service provider, in text to the cockpit or gate printer.
