# CONTROLLER PILOT DATA LINK COMMUNICATIONS (CPDLC)

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-c.html#CONTROLLER_PILOT_DATA_LINK_COMMUNICATIONS_CPDLC)

## Official Text

CONTROLLER PILOT DATA LINK COMMUNICATIONS (CPDLC)- A two-way digital communications system that conveys textual air traffic control messages between controllers and pilots using ground or satellite-based radio relay stations.
