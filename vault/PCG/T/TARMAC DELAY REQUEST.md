# TARMAC DELAY REQUEST

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-t.html#TARMAC_DELAY_REQUEST)

## Official Text

TARMAC DELAY REQUEST- A request by the pilot-in-command to taxi to the ramp, gate, or alternate deplaning location to comply with the Three-hour Tarmac Rule.
