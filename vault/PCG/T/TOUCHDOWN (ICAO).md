# TOUCHDOWN \[ICAO]

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-t.html#TOUCHDOWN)

## Official Text

TOUCHDOWN \[ICAO]- The point where the nominal glide path intercepts the runway.

> [!note] Note:
> Touchdown as defined above is only a datum and is not necessarily the actual point at which the aircraft will touch the runway.
