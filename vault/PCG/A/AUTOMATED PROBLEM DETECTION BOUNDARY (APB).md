# AUTOMATED PROBLEM DETECTION BOUNDARY (APB)

## Official Text

AUTOMATED PROBLEM DETECTION BOUNDARY (APB)- The adapted distance beyond a facilities boundary defining the airspace within which EDST performs conflict detection.
