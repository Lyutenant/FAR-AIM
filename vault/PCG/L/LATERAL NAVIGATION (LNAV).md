# LATERAL NAVIGATION (LNAV)

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-l.html)

## Official Text

LATERAL NAVIGATION (LNAV)– A function of area navigation (RNAV) equipment which calculates, displays, and provides lateral guidance to a profile or path.
