# LANDING DISTANCE AVAILABLE \[ICAO]

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-l.html)

## Official Text

LANDING DISTANCE AVAILABLE \[ICAO]- The length of runway which is declared available and suitable for the ground run of an aeroplane landing.
