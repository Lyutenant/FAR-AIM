# METER REFERENCE ELEMENT (MRE)

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-m.html#METER_REFERENCE_ELEMENT_MRE)

## Official Text

METER REFERENCE ELEMENT (MRE)- A constraint point through which traffic flows are managed. An MRE can be the runway threshold, a meter fix, or a meter arc.
