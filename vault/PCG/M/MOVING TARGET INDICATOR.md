# MOVING TARGET INDICATOR

> [!info] Source
> FAA Pilot/Controller Glossary, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/pcg_html/glossary-m.html#MOVING_TARGET_INDICATOR)

## Official Text

MOVING TARGET INDICATOR- An electronic device which will permit radar scope presentation only from targets which are in motion. A partial remedy for ground clutter.
