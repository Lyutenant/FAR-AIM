# § 25.1159 — Supercharger controls

> [!info] Source
> eCFR Title 14, issue 2026-09-03 — [view on eCFR](https://www.ecfr.gov/on/2026-09-03/title-14/section-25.1159)

## Official Text

Each supercharger control must be accessible to the pilots or, if there is a separate flight engineer station with a control panel, to the flight engineer.
