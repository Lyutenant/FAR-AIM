# Appendix B to Part 1215—Factors Affecting Standard Charges

> [!info] Source
> eCFR Title 14, issue 2026-09-03 — [view on eCFR](https://www.ecfr.gov/on/2026-09-03/title-14/part-1215)

## Official Text

Charges for services shall be determined by multiplying the factors below by the base rates for standard services set forth in appendix A.

|  | Flexible | Time or position constrained | Emergency service, disruptive updates |
| --- | --- | --- | --- |
| Single access service | .5 | 1 | 2 |
| Multiple access forward (command) service | .67 | 1 | 2 |

|  | Normally scheduled support | Emergency service, disruptive updates |
| --- | --- | --- |
| Multiple access return (telemetry) service | 1 | 2 |
