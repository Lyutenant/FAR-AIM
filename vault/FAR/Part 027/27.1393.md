# § 27.1393 — Minimum intensities in any vertical plane of forward and rear position lights

> [!info] Source
> eCFR Title 14, issue 2026-08-19 — [view on eCFR](https://www.ecfr.gov/on/2026-08-19/title-14/section-27.1393)

## Official Text

Each position light intensity must equal or exceed the applicable values in the following table:

| Angle above or below the horizontal plane | Intensity, l |
| --- | --- |
| 0° | 1\.00 |
| 0° to 5° | 0\.90 |
| 5° to 10° | 0\.80 |
| 10° to 15° | 0\.70 |
| 15° to 20° | 0\.50 |
| 20° to 30° | 0\.30 |
| 30° to 40° | 0\.10 |
| 40° to 90° | 0\.05 |
