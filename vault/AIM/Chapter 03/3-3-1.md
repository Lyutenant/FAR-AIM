# AIM 3-3-1 — General

> [!info] Source
> FAA Aeronautical Information Manual, Basic with Change 1, 2 and 3 (effective 2026-07-09) — [view on FAA](https://www.faa.gov/air_traffic/publications/atpubs/aim_html/chap3_section_3.html#3-3-1)

## Official Text

Class G airspace (uncontrolled) is that portion of airspace that has not been designated as Class A, Class B, Class C, Class D, or Class E airspace.
